# My Portfolio — Bintou Fofana

Portfolio personnel présentant mon parcours, mes compétences et mes projets en développement web.

## ✨ Aperçu

Ce site à une seule page (single page) présente :
- **Accueil** — présentation rapide, CV téléchargeable et réseaux sociaux
- **À propos** — carte professionnelle et présentation personnelle
- **Compétences** — HTML, CSS, JavaScript, C, Python, PHP (barres de progression animées)
- **Projets** — Fofana-World Travel, ConnectX, To-Do List, avec fenêtres modales de détails
- **Contact** — formulaire fonctionnel connecté à Formspree

## 🛠️ Technologies utilisées

- **HTML5** — structure sémantique
- **CSS3** — mise en page, animations, thème clair/sombre
- **JavaScript (Vanilla)** — interactions (menu, thème, modales, formulaire, effets de défilement)
- **Font Awesome** — icônes
- **Google Fonts (Poppins)** — typographie
- **Formspree** — traitement du formulaire de contact

## 🚀 Fonctionnalités

- Menu de navigation responsive (mobile/burger menu)
- Navbar qui change d'apparence au défilement
- Mise en surbrillance automatique du lien de section active
- Animations d'apparition au scroll (`reveal`)
- Bascule thème clair / sombre avec sauvegarde de la préférence (localStorage)
- Fenêtres modales détaillant chaque projet
- Formulaire de contact avec envoi asynchrone (fetch) et retour utilisateur

## 📁 Structure du projet

```
├── index.html      # Structure et contenu du site
├── style.css       # Mise en forme et thèmes
├── script.js       # Interactions et logique JavaScript
└── medias/         # Images (photo de profil, aperçus de projets)
```

## ▶️ Utilisation en local

1. Cloner ou télécharger ce dépôt
2. Ouvrir `index.html` dans un navigateur (ou utiliser une extension type Live Server)
3. Aucune installation ni dépendance nécessaire — le projet fonctionne en HTML/CSS/JS pur
